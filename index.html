Surgical Scheduling Variance Analysis

Hospital operations and capacity analysis

Open live dashboardView on GitHub

Problem

The operating room is the most expensive part of a hospital to run, so every minute counts. When surgeries run far over or finish far early, hospitals pay for staff overtime, patients wait longer, and staffed rooms sit empty, but leaders cannot see the total cost or which surgeries cause it.

What I did

  • Compared 48.1K surgeries with how long each type usually takes.
  • Estimated what the misses cost: 7,539 operating room hours a year.
  • Built an interactive Power BI dashboard that ranks surgery types for hospital leaders to review first.
  • Found that early finishes leave 2,167 room hours a year unused, about one staffed operating room sitting empty every working day.
  • Power BI
  • DAX
  • Microsoft Fabric
  • PySpark

Key findings

  • $15.8M to $27.1Mestimated yearly cost of scheduling misses
  • 53.3%of surgeries off schedule by 30+ minutes
  • 133 of 418surgery types cause over half (53.6%) of the missed time

Cost range assumes $35 to $60 per operating room minute.

Medicare Claims Payment Integrity

Healthcare payment accuracy

View on GitHub

Problem

Improper payments cost Medicare billions every year. One health plan checked every claim by hand: reviewers spent an estimated $425K working through long queues of mostly clean claims, payments slowed, and 99 claims that failed a billing-rule check still slipped through and got paid.

What I did

  • Cleaned and organized 10 messy data files into one reliable database.
  • Translated Medicare billing rules into 10 SQL-based checks that flag problem claims automatically, and tested them against the health plan's real decisions.
  • Built a Power BI report showing which claims can be denied automatically, which still need a person to review, and which providers to contact.
  • SQL
  • Python
  • PostgreSQL
  • Power BI

Impact

  • $425K → $120Kestimated review cost
  • 23.6K → 854claims needing a manual review
  • 82%of incorrect claims caught before payment

Built with sample claims that follow real Medicare file formats.

Statistical Time-Series Analysis

Stock market trends and patterns

View on GitHub

Objective

Investors often judge a stock by its return alone. I analyzed five years of Apple stock to find the trends and patterns behind its 112.8% growth, and whether that growth came with more risk.

Analysis

  • Tracked price trends, yearly returns, and daily price swings over 1,254 trading days.
  • Looked for patterns by month and weekday, and flagged unusual periods such as spring 2025.
  • Tested which patterns were real. Trading volume showed no real link to price direction, and month and weekday patterns were too weak to rely on.
  • Python
  • pandas
  • SciPy
  • Matplotlib

Key findings

  • $146 → $311112.8% total return, with most of the gain in 2023 and 2024, right after a -28.6% year in 2022
  • 1.65%average daily price swing, which did not rise as the price doubled
  • 4.4%typical daily move at the spring 2025 peak, more than 2.5 times the 1.65% average
